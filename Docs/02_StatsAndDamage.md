# Project Slayers - Stats and Damage

상태: 현재 활성 게임 시스템 기준  
용도: 게임 스탯, 런타임 자원 분리, 피해 계수 저장 단위, 피해 계산식 구현 기준

---

## 1. 스탯 기본 원칙

정적 정의 데이터와 런타임 상태를 분리한다.

예:

- 캐릭터 기본 정의
- 레벨 성장 정의
- 런타임 최종 스탯
- 장비 Modifier
- 버프/디버프 Modifier
- 현재 HP / MP / 게이지

ScriptableObject 정의 에셋 자체를 런타임 저장 상태로 사용하지 않는다.

---

## 2. 확정 스탯

[ACTIVE UPDATE 2026-10-18]

- 각성 능력치를 제거한다. 독립 성장/Modifier 스탯은 35종이다.
- 세부 스탯창은 기본 8종, 세부 12종(파생 무력화 게이지 포함), 속성 16종으로 표시한다.
- 기본: 체력, 마나, 공격력, 마력, 방어력, 저항력, 물리 관통력, 마법 관통력.
- 세부: 무력화, 무력화 게이지, 치명타 확률, 치명타 데미지, 공격속도, 이동속도, 적중률, 회피율, 상태이상 저항력, 회복력, 쿨타임 감소, 행운.
- 속성: 화염, 물, 대지, 바람, 번개, 얼음, 빛, 어둠 순서의 강화 8종과 저항 8종.
- 무력화 게이지는 최종 체력 × 정의된 체력 비율 / 100으로 계산하며 독립 StatType에 추가하지 않는다.
- Town은 메이헴을 기본 표시하고 같은 실행 세션의 전투 진입 캐릭터 선택을 연동한다. 현재 전투 선택 레벨은 기존과 같이 1이다.

현재 확정 스탯:

속성 관련:

- 관통력은 유지한다.
- 자원 효율 스탯은 삭제된 상태다.
- 기존 가드 게이지 명칭은 무력화 게이지로 대체한다.

## 3. 기본 속성

기본 속성 8종:

1. 화염
2. 물
3. 대지
4. 바람
5. 번개
6. 얼음
7. 빛
8. 어둠

피해 구현에서는 공격 기반과 공격 속성을 분리한다.

예:

- 물리 기반 + 물리 속성
- 물리 기반 + 화염 속성
- 마법 기반 + 얼음 속성

공격 기반이 방어력/저항력 계산 대상을 정하고,
공격 속성이 속성 강화/저항 계산을 정한다.

---

## 4. 피해 계수 저장 단위

피해 계수는 정수 퍼센트로 저장한다.

예:

- `100` = 1.00배
- `150` = 1.50배
- `396` = 3.96배

코드에서 저장값 자체를 1.5, 3.96으로 변경하지 않는다.

---

## 5. 기본 피해

### 물리 기반

`공격력 × 피해 계수 / 100`

### 마법 기반

`마력 × 피해 계수 / 100`

---

## 6. 크리티컬 배율

비치명타:

`1`

치명타:

`1 + 크리티컬 데미지 / 100`

예:

크리티컬 데미지 200이라면:

`1 + 200 / 100 = 3.0`

---

## 7. 속성 배율

### 물리 속성

`1`

### 8개 원소 속성

`max(0, 1 + (속성 강화 - 대상 속성 저항) / 100)`

적용 대상:

- 화염
- 물
- 대지
- 바람
- 번개
- 얼음
- 빛
- 어둠

배율 결과가 음수가 되면 0으로 처리한다.

---

## 8. 방어 / 저항 배율

### 물리 기반

`max(0, 1 + (물리 관통력 - 대상 방어력) / 100)`

### 마법 기반

`max(0, 1 + (마법 관통력 - 대상 저항력) / 100)`

규칙:

- 결과가 음수가 되면 0
- 관통력이 방어력/저항력보다 높으면 차이만큼 배율이 증가한다.

---

## 9. 최종 피해

`max(0, 기본 피해 × 크리티컬 배율 × 속성 배율 × 방어/저항 배율)`

구조:

1. 기본 피해 계산
2. 크리티컬 배율
3. 속성 배율
4. 방어/저항 배율
5. 최종 0 미만 방지

---

## 10. 구현 예시

예시 값:

- 물리 기반
- 공격력 422
- 피해 계수 150
- 치명타
- 크리티컬 데미지 200
- 화염 속성
- 화염 강화 30
- 대상 화염 저항 10
- 물리 관통력 20
- 대상 방어력 10

기본 피해:

`422 × 150 / 100 = 633`

크리티컬 배율:

`1 + 200 / 100 = 3`

속성 배율:

`1 + (30 - 10) / 100 = 1.2`

방어 배율:

`1 + (20 - 10) / 100 = 1.1`

최종:

`633 × 3 × 1.2 × 1.1`

이 예시는 계산 구조를 설명하기 위한 예이며,
게임 내 특정 스킬의 확정 피해값을 뜻하지 않는다.

## 11. 런타임 자원

정의 데이터와 별도로 현재값이 필요한 항목 예:

- 현재 체력
- 현재 마나
- 현재 무력화 게이지
- 쿨다운
- 충전 횟수
- 임시 버프/디버프
- 현재 액션 상태

현재값을 ScriptableObject 원본 에셋에 직접 기록하지 않는다.

## 13. 미확정 피해 규칙

다음은 아직 구현 규칙이 확정되지 않았다.

- 소수점 처리
- 최종 피해 반올림 시점
- 최소 피해
- 스탯 상한
- 고정 피해 처리
- 방어 무시
- 보호막
- 무적
- 피해 흡수
- 피해 반사
- 다단 히트 적용 순서
- 한 번의 액션 내 여러 히트의 개별/공통 판정
- 상태이상과 피해의 적용 순서
- 치명타 불가 공격 처리
- 고정 크리티컬과 크리티컬 확률의 관계

임의로 보완하지 않는다.

---

## 14. 코드 구현 시 주의

- 공격 기반과 속성을 하나의 enum으로 합쳐 의미를 잃지 않는다.
- 피해 계수 저장값은 정수 퍼센트 원칙을 유지한다.
- 방어/저항 공식은 일반적인 RPG 공식으로 임의 교체하지 않는다.
- 미확정 규칙이 필요한 기능은 구현 전에 보고한다.
